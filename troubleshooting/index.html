    Troubleshooting¶

    First check

    Confirm command path and mode (standard vs --bevel-graph) before deeper debugging.

    Missing OpenAI Key¶

    • Symptom: enrichment/fix quality drops to fallback heuristics.
    • Fix: set OPENAI_API_KEY in environment or .env.

    Invalid Folder Path¶

    • Symptom: ValueError: Invalid folder path.
    • Fix: verify --folder points to a real Python project directory.

    No Python Files Found¶

    • Symptom: RuntimeError: No Python files found under ....
    • Fix: ensure the target contains .py files and pass the correct root folder.

    Bevel Graph Format Error¶

    • Symptom: adapter schema/format parsing error.
    • Fix: re-export valid Bevel JSON and pass correct --bevel-graph file path.

    Debug Agent Input Issues¶

    • Provide exactly one source: --error-text or --error-file.
    • For large traces, include failing frame + final exception line.

    Auto-Fix Apply Rollback¶

    • Symptom: edits applied and then reverted.
    • Cause: validation command returned non-zero exit code.
    • Fix: inspect outputs/autofix_report.json, adjust patch/validation command, rerun.

    MkDocs Build or Publish Issues¶

    • Ensure all files in mkdocs.yml nav exist under docs/.
    • Run mkdocs build --strict locally before push.
    • Ensure GitHub Pages is enabled for the repository branch/pages setup.

    Quick Diagnostics¶

    python main.py --folder ../book_synthesiser
python debug_agent.py --error-text "ValueError: invalid payload shape"
python autofix_agent.py --error-text "ValueError: invalid payload shape in run_pipeline"
mkdocs build --strict
