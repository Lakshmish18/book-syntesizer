# Book Syntesizer

This repository contains the Book Syntesizer project source code.

## Project structure

- `book_synthesiser/` - main application package and pipeline modules

## Quick start

1. Install dependencies:
   - `pip install -r book_synthesiser/requirements.txt`
2. Run system check:
   - `python book_synthesiser/main.py --test`
3. Run pipeline validation:
   - `python book_synthesiser/main.py --stage validate`
